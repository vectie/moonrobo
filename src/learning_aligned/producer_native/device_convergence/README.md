# Device convergence transitions

This package ports actual MuJoCo-Warp 3.15 solver convergence arithmetic to
typed CUDA generated by MoonBit. The original Python and CPU/Double ports remain
available. No test, numeric algorithm, GPU operation, SDK or NVRTC compilation was
executed while implementing this package.

`lower(Request)` is a source-only typed lowerer. The request contains `nworld`,
`nv`, positive `iterations`, `warn_overflow` and `kernels`. Supported keys are
`newton-done`, `cg-beta-finalize`, `newton-done-with-ls` and
`cg-beta-search-finalize`. The latter two compose the actual Newton/CG iteration:
the line-search overflow is merged into the preserved public bits, and the CG
tail updates actual search/history/norm only for unfinished worlds. Warning-print variants are deliberately
rejected: `warn_overflow` must be zero. Both modes still set the real iteration
overflow bit 512 when an unfinished world reaches its iteration limit.
Dimensions and iteration limits are bounded; option tolerance and mean inertia
arrays must each have either one element or `nworld` elements.

The Newton transition retains `_solve_done`: skip an already done world,
increment its real `solver_niter`, divide improvement, gradient norm and half
Newton decrement by `meaninertia * nv`, apply the original strict convergence
comparisons, mark done at convergence or the exact iteration limit, and atomically
subtract one from `nsolving` once. The CG transition additionally computes the
original nonnegative Polak–Ribiere beta numerator/denominator with `1e-15` floor,
using the actual supplied current and previous gradient/preconditioned vectors.
It retains CG's own convergence tests without adding the Newton-decrement test.

Each generated CUDA thread owns one world. CG uses an explicit serial FP32
reduction over `nv`; it does not reproduce upstream's tiled reduction association.
Numerical and learning equivalence therefore remain unverified. The upstream
done input/output descriptors refer to the same `ctx.done` array; this ABI merges
them into one explicit `ctx_done` inout descriptor, avoiding an implicit writable
alias requirement. There are no replacement placeholder solver calls.

`validate_bindings(request, key, bindings)` checks actual owned-buffer metadata:
exact primitive dtypes, concrete world/vector extents, positive scalar-aligned
strides and offsets, full reachable byte spans, self-aliasing and all writable
cross-parameter overlaps. It performs no arithmetic transition or allocation.

`compile_specialization(CompileConfig)` is an explicit async native compiler
interface. It verifies the fixed solver/constant source and genuine Warp ABI
headers, inventories native header bytes, calls the real existing C NVRTC binding,
and saves source, original source snapshots, headers, image and compile receipt.
It is never invoked by `lower`, validation, `moon check`, `moon info` or `moon fmt`.
The receipt format is `moonrobo-device-convergence-module-v1`; it specifies the
real array-by-value Warp 1.17 launch ABI and launch policy. No `.meta` is fabricated.

The existing `gpu_pipeline` accepts this receipt and requires its producer as the
unconditional final launch of a top-level device WHILE. Its `nsolving` view must
exactly match the native graph predicate. Before CUDA setup, actual initial bytes
must prove `nsolving == count(!done)` and unfinished `niter < iterations`. The four
control owners (`ctx_done`, `solver_niter`, `overflow`, `nsolving`) are distinct and
may only be written by that unique producer, with narrow authenticated exceptions
for the real top-level Newton `initialize-controls` and CG `cg-search-init`.
Those initializers must precede the matching WHILE and bind exactly the same
control/state views. Every other kernel, copy and zero is rejected recursively
across branches. Tolerance/inertia owners are immutable.
Consequently each active world increments to its limit or converges, subtracts
once, and the real device predicate reaches zero in finitely many iterations.
No fixed-repeat loop or CPU-predicate fallback is used. After an actual graph
launch, the host requires count zero, all done and in-range iteration counts.
Record-only capture makes no result-validation claim.

This adds convergence state updates and native conditional-loop orchestration.
The separate `newton_solver` package now supplies the actual full-rebuild
line search, gradient/Hessian, constraint and factorization schedule, while
`solver_adapters` adds real compact/incremental paths. This package continues
to consume genuine preceding operations; no synthetic values are substituted. Full solver closure and runtime
equivalence remain false. Metadata-only pending regressions are included; all
execution and upstream differential tests await an available machine.
