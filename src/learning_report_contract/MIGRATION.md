# Native report contracts

The six `scripts/report_g1_{learned_balance,sustained_balance,balance_teacher_long,balance_intervention,balance_long_intervention,balance_features}.mbtx` entry points accept the retained Python report schema and the actual native schema. No interpreter is launched. Existing numerical thresholds, corpus sizes, case/reset coverage, physical-log hashes, frozen-weight checks, and exact refit requirements remain enforced.

Native study writers capture actual `.mbt` sources into `provider-sources/<digest-field>.mbt`, record their original paths, digest, and role in `native_source_files`, and verify source bytes are unchanged before saving the report. The report readers verify every recorded snapshot and its top-level digest. A historical Python teacher-parameter source may be copied with its actual `.py` extension and the explicit `passive-parameter-source` role; native teacher implementation/algorithm snapshots remain separate. A native report without these bindings is rejected and must be regenerated. Existing reports are not relabeled or assigned invented Python digests.

`pooled` derives both original flat statistics/per-case arrays and the native nested `summary` from the same actual trials. Teacher-long output retains its original canonical/audit grouping, binds each episode to role/scope, and records actual search/evaluation transition counts. Feature verification exposes the actual oracle statistics and the original `full` window label. Intervention implementation provenance is separate from teacher provenance.

Checkpoint selection requires exactly one actual `.moon.json`, `.pt`, or `.json` file per stem; file bytes determine the digest. The sustained reporter invokes `learning_balance/verification/cli` through the shared native launcher. The verifier passively reads supported Torch checkpoints, verifies the real v1 loaders reject v2, and demands exact refitted tensors. Any Float32/Double difference fails; no tolerance or parity claim was introduced.

Validation performed: six standalone MoonBit report source checks, two standalone export wrapper checks, affected native package checks, local `moon info` and `moon fmt`. The two new pooled-contract test sources were typechecked only. No report, test, Python interpreter, SDK, training, simulation, or export was executed. Runtime numerical parity and external SDK/GPU availability remain unverified.
