# Read-only E1 live view

Run `npm ci`, `npm run test:e1-live`, then `npm run dev:e1-live` from the parent
directory. Open `http://127.0.0.1:5300/e1-live.html`. Set
`MOONROBO_E1_LIVE_FILE` to the private atomic pose file generated by the
[receive-only relay](../../../deploy/e1/README.md). Without a fresh source the
measured pane reports unavailable; it does not animate a simulated live pose.

The measured model uses named joint angles and IMU orientation; root position
is fixed. Cameras rotate together. The reference pane offers the earlier left
elbow clip and the current nominal dual-elbow sequence: −90° raise, alternating
30° drops to −60°, then return. Play, scrub and pose buttons only affect the
reference. The nominal 171-second timeline cannot show feedback pacing or
establish physical command acceptance. The optional shadow pane requires an
explicit recorded shadow file and is labeled as such.

`npm run build:e1-live` produces a standalone `dist-e1-live` build. Its read-only
API is installed by the dedicated Vite config for local dev/preview. A generic
static host can show the reference but has no live endpoint. The original
cockpit build and its backend remain independent.

The 23-joint geometry is derived from the supplied Noetix E1 assembly model.
The converted binary meshes use a 2 mm grid; `manifest.json` records hashes
checked at load time. Redistribution retains `public/e1/assets/NOETIX-LICENSE.txt`
(BSD 3-Clause). This live-only manifest includes no training trajectories,
checkpoints or policy result clips. See the
[commissioning findings](../../../docs/E1_COMMISSIONING_FINDINGS.md) for the
measured powered results and their limits.
